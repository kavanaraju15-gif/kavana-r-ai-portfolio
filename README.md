# Kavana R — Portfolio

A responsive portfolio inspired by the uploaded reference video: editorial typography, warm cream background, black sections, oversized headings, project cards, and a strong contact section.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — reveal animations

## Before publishing
1. Replace `your.email@example.com` with your email.
2. Replace the education placeholders with your exact degree, college and dates.
3. Add your GitHub URL and resume file.
4. Update project links when you have live demos/GitHub repositories.

The LinkedIn button is prefilled with your LinkedIn profile.
